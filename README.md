# Paper2ARM Hackathon Artifacts

This repository is a collection of seven challenge solution packages and their supporting code, reports, result files, and execution traces.

## Artifact Index

- `q1_deepmd/` and `submission_q1_deepmd_arm.zip` — DeePMD workflow artifacts
- `q2_wind/` and `submission_q2_wind/` — wind-wake fitting artifacts
- `q3_rustbca/` and `submission_q3_rustbca_arm.zip` — RustBCA-related simulation artifacts
- `q4_huggett/` and `submission_q4_huggett_arm.zip` — Huggett-model artifacts
- `q5_hic/` and `submission_q5_hic_arm.zip` — Hi-C analysis artifacts
- `q6_anion/` and `submission_q6/` — molecular-classification artifacts
- `q7_tsaseq/` and `submission_q7_tsaseq_arm.zip` — TSA-seq analysis artifacts

## Evidence Boundary

Files in this repository document the contents and outputs of the included solution packages. A local result, trace, validation file, or packaging check does not by itself establish an externally evaluated outcome or independent reproduction.
